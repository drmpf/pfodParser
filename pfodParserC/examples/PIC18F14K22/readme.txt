pfodParserC example for PIC18F14K22 - EUSART, an on/off slider sets RC0 low or high.
The slider text shows RC0 0 or RC0 1.

Generated by pfodWeb V4.1.14 (Minimal C target) from menujson/EmptyMenu.pfodMenu_json
pfodParserStream.c is pfodParserStream_PIC18F14K22.c from pfodParserC, unchanged.
main.c adds the MCC init calls and RC0 output setup, and sets RC0 from onoff_RC0_var in its loop.

Build with MPLAB X and the XC8 compiler. This directory does not include the MCC driver.
Use MPLAB Code Configurator (MCC) to generate mcc_generated_files/ into this directory, with:
  - the EUSART driver interrupt driven, as pfodParserStream.c reads
    eusartTxBufferRemaining and eusartRxCount
  - STDIO redirect enabled, as pfodParserStream.c calls putch() and getch()
  - your clock, baud rate and pins

main.c calls INTERRUPT_GlobalInterruptEnable() and INTERRUPT_PeripheralInterruptEnable().
If interrupt priorities are enabled in MCC, change these to the High/Low priority versions.

Expected reply to {.} is {,~Initial Empty Menu`0~V1|A`0~RC0 ~~0\1~}
Moving the slider sends {A`1} or {A`0}, the reply is {;|A`1} or {;|A`0}
