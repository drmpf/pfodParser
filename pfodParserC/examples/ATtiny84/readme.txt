pfodParserC example for ATtiny84 - interrupt driven software serial, an on/off slider sets PA0 low or high.
The slider text shows PA0 0 or PA0 1.

Generated by pfodWeb V4.1.14 (Minimal C target) from menujson/EmptyMenu.pfodMenu_json
pfodParserStream.c and pfodParserStream_ATtiny84.h are copies of pfodParserStream_ATtiny84.c/.h from pfodParserC.
main.c adds the PA0 output setup and sets PA0 from onoff_PA0_var in its loop.

Serial: 9600 baud, TX PA1, RX PA2 (set in pfodParserStream.c)
Clock:  8MHz internal RC. pfodParserStream_init() sets the clock prescaler to 1,
        so no fuse change is needed. Code that runs before pfodParser_setup() may run at 1MHz.
Timers: Timer1 and PCINT0 are used by the serial code and micros(), do not change their settings.
        Timer0 is free. pfodParser_setup() enables global interrupts.

micros(): #include "pfodParserStream_ATtiny84.h" to use it, it counts from pfodParser_setup().
        Rolls over about every 71.6 minutes, use (micros() - start) to measure an interval.

Build:
  avr-gcc -mmcu=attiny84 -Os main.c pfodMenu.c pfodParser.c pfodParserStream.c -o EmptyMenu.elf

F_CPU must be 8MHz, any other value gives a compile error.
RX_LATENCY_TICKS in pfodParserStream.c is counted from the avr-gcc -Os output, recheck it if the receive interrupts change.

Size with avr-gcc 14.1.0: 2340 bytes flash, 128 bytes RAM.
Expected reply to {.} is {,~Initial Empty Menu`0~V1|A`0~PA0 ~~0\1~}
Moving the slider sends {A`1} or {A`0}, the reply is {;|A`1} or {;|A`0}
