# pfodParserC
pfodParserC is the plain C version of pfodParser, for small micros with no C++ compiler or little memory,
e.g. PIC16/PIC18 with XC8, or AVR without Arduino. It serves menus to
[pfodWeb](https://www.forward.com.au/pfod/pfodWeb/index.html)
over a serial connection.  
Drawings are not supported.

There is no library to install. The pfodWeb Designer generates the parser along with the code for your menu.
Select the **Minimal C code no Dwgs** target and press Generate Code. A design can have up to 52 items that need a cmd.

See section 5.8 of the [AI guide](../pfodWeb/docs/pfodAI-guide.md) for the generated code.

## Generated files
| File | Purpose |
|---|---|
| `main.c` | starting point for your program: init, then the parse loop |
| `pfodMenu.h`, `pfodMenu.c` | the menu, its command dispatch and its variables |
| `pfodParser.h`, `pfodParser.c` | the parser, your code does not need to change this |
| `pfodParserStream.h` | the serial interface the parser calls |
| `pfodParserStream.c` | template, you complete this for your micro's serial port |
| `menujson/` | the design that produced this code |

Your code uses the `<item>_var` variables declared in `pfodMenu.h`. Regenerating overwrites your edits,
so generate into a different directory and merge the changes.

## Examples
Each example in [examples/](examples/) has an on/off slider that sets one output pin low or high, a completed
`pfodParserStream.c`, and a `readme.txt` with its build steps and the expected messages.

| Example | Serial | Output pin | Slider text | Build with |
|---|---|---|---|---|
| [ATtiny84](examples/ATtiny84/) | interrupt driven software serial, 9600 baud, TX PA1, RX PA2 | PA0 | `PA0 0` / `PA0 1` | avr-gcc |
| [PIC18F14K22](examples/PIC18F14K22/) | EUSART, using the driver generated by MCC | RC0 | `RC0 0` / `RC0 1` | MPLAB X and XC8, after generating `mcc_generated_files/` with MCC |

The ATtiny84 example:
* runs at 8MHz from the internal oscillator, set in `pfodParserStream_init()`, so no fuse change is needed
* uses Timer1 and PCINT0 for serial, Timer0 is left free
* adds `micros()`, see `pfodParserStream_ATtiny84.h`
* needs 2340 bytes of flash and 128 bytes of RAM, plus stack, built with avr-gcc 14.1.0.


## Using your own micro
Copy the closest example's `pfodParserStream.c` and replace its body with calls to your UART driver:-
* `pfodParserStream_init()`, any one-time serial setup
* `pfodParser_TXfree()`, the space available to write
* `pfodParser_write(uint8_t c)`, write a byte, spin if there is no space
* `pfodParser_RXavailable()`, the bytes available to read
* `pfodParser_read()`, read a byte, spin if none are available

Every command must get a pfod message in reply, otherwise pfodApp disconnects.
If you change what `pfodParser_sendMenu_<Name>()` sends, also change the version passed to `pfodParser_pfodParser()`
in `pfodParser_setup()` OR Clear Menu Cache in pfodWeb, otherwise a client that has cached the menu keeps showing the old one.
